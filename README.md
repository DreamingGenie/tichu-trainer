# 티츄 트레이너

보드게임 **티츄(Tichu)** 의 규칙을 설명하고, 상황마다 어떻게 두는 게 좋은지 퀴즈로 연습해보는 웹 페이지입니다.

친구에게 티츄 규칙을 설명했는데 잘 전달되지 않았습니다. 생각해보니 저도 설명을 듣고 이해한 게 아니라
몇 판 해보면서 익혔습니다. 그래서 읽기만 하는 규칙 문서 대신, 각 규칙을 그 자리에서 직접 해볼 수 있게 만들었습니다.

## 무엇이 들어 있나

- **규칙 설명 10챕터** — 조합, 트릭 진행, 특수 카드, 폭탄, 카드 교환, 티츄 선언, 점수 계산, 파트너 플레이
- **연습문제** — 카드를 직접 골라서 내면 낼 수 있는지 판정하고, 안 되면 이유를 알려줍니다
- **미니판 5개** — 짧은 상황을 실제로 여러 턴 플레이합니다
- **조합 판정 샌드박스** — 카드를 아무렇게나 골라보면 무슨 조합인지, 테이블에 깔린 걸 이기는지 보여줍니다

진도는 브라우저에 저장됩니다.

## 실행

설치할 패키지도 빌드 단계도 없습니다. 다만 ES 모듈을 쓰기 때문에 HTML 파일을 직접 열면 동작하지 않고
서버가 필요합니다. 저장소에 의존성 없는 서버 스크립트를 같이 넣어뒀습니다.

```bash
node tools/serve.js 8000
```

띄운 뒤 <http://localhost:8000> 으로 접속하면 됩니다.

## 테스트

```bash
node tests/run.js
```

조합 판정, 받아치기, 참새 소원, 점수 계산, 트릭 진행, 미니판 각본, 그리고 챕터에 적어둔 카드 표기가
전부 맞는지 확인합니다. 브라우저 없이 돌아갑니다.

카드가 실제로 어떻게 그려지는지는 서버를 띄운 뒤 `/tests/cards.html` 에서 볼 수 있습니다.

## 폴더

```
index.html          진입점 (해시 라우팅)
styles/             색·간격 토큰, 기본 스타일, 부품 스타일
src/
  engine/           규칙 판정 로직. 화면 코드를 전혀 참조하지 않습니다
  ui/               카드 SVG, 손패, 테이블, 레슨 블록, 데모
  views/            화면 (목록 / 레슨 / 퀴즈 / 미니판)
  data/             챕터 본문, 퀴즈, 미니판 각본
  store/            진도 저장 (localStorage)
tests/              테스트
tools/serve.js      개발용 정적 서버
```

퀴즈 채점, 미니판 진행, 샌드박스 판정이 모두 `src/engine` 의 같은 함수를 씁니다.
그래서 세 곳의 판정이 어긋날 일이 없습니다.

규칙 텍스트와 문제는 `src/data` 안에 데이터로만 들어 있어서, 내용을 고칠 때 화면 코드를 건드릴 필요가 없습니다.

## 규칙 기준

Fata Morgana / Rio Grande의 공식 룰북을 따랐습니다. 헷갈리기 쉬운 부분은 이렇습니다.

- 봉황은 폭탄에 들어갈 수 없고, 용은 어떤 조합에도 들어갈 수 없습니다.
- 스트레이트 플러시 폭탄은 랭크보다 길이가 먼저입니다.
- 패스해도 그 트릭에서 빠지는 게 아닙니다. 세 명이 연달아 패스해야 트릭이 끝납니다.
- 봉황으로는 참새의 소원을 이행할 수 없고, 자기 차례가 아닐 때 낸 폭탄은 소원 의무에서 면제됩니다.

카드 그림은 직접 그린 SVG라 실제 티츄 카드의 디자인과는 다릅니다.
